## LabMatch – Smart Lab Allocation System

**Live Demo:** https://labmatch-frontend-ngzt.onrender.com  
**Backend API:** https://labmatch-backend-dglg.onrender.com

**Description:**  
Developed a smart lab allocation system that automates student-to-lab assignments using the Hopcroft–Karp maximum bipartite matching algorithm, ensuring efficient and capacity-aware allocation.

**Key Features:**
- Automated student-to-lab allocation using maximum bipartite matching.
- Excel file upload for student and laboratory data.
- Lab capacity management and allocation statistics.
- Visual seating layouts for allocated students.
- Matching results visualization for efficient lab management.

**Technologies Used:** Java, Maven, HTML, CSS, JavaScript, Hopcroft–Karp Algorithm, Render.

**Deployment:** Frontend and backend deployed on Render.
